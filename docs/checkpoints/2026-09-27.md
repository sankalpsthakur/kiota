### Strict remote supervisor preparation

`scripts/remote/runner.py` verifies manifest bytes/hash/export headers, an
actual immutable fresh Git checkout, locked offline builds and toolchain/binary
provenance, then checks valid corpora serially. Missing inputs, incomplete runs,
rejects, declines, crashes and timeouts fail the aggregate. It separates fake
binary/existing-checkout proxy results from source-associated validation and
explicitly records that manifest completion is not full Arena coverage or rank.

The supervisor clears inherited evaluation/compiler overrides, bounds logs and
cleanup, preserves the child's wait record until group signalling, and aborts
after any cleanup failure (including optional probes and simultaneous input
mutation). Hardware probes require positive instructions with valid full event
coverage and record privilege scope; they are never corpus ranking metrics.
All 29 fake-binary supervisor tests pass locally in 11.77 seconds; normal Linux
CI executes the same tests. This is supervisor evidence, not real-corpus proof.
Inputs/toolchain must be supplied externally; build scripts are not network
sandboxed and processes creating new sessions are outside group cleanup.
